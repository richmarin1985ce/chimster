# Minigame Editor
Portable original minigame projects, local preview and target-specific native packaging planned. The initial grid-adventure format uses # wall, . floor, S start, C collectible and E exit. The validator rejects unreachable collectibles or exits. Export creates a self-contained offline keyboard/touch HTML game; no external scripts, proprietary assets, runtime dependencies or game integration. Example: Mother Road Dispatch, an original Route 66 cargo game.
    python -m chimster minigame examples/flagstaff/pipgame.json output
Open output/play.html. Native Fallout 4 games need Scaleform SWF and appropriate holotape records; investigate ActionScript compilation and licensed framework APIs. New Vegas needs a separate UI/script extender or holotape framework, such as https://www.nexusmods.com/newvegas/mods/95124 ; assess its license/API before integration. Do not claim HTML runs natively. Fallout 76 remains offline authoring/research only. Roadmap: visual tile editor, sprites, animation, input mapping, sound, scoring, save states, multiple genres, native packaging and engine validation. No backend emulation.
