# Rendering integration follow-up
Panda PBR preview now supplies mesh tangent frames, normal-map stages, DirectX normal Y conversion, normal strength and dielectric roughness derived from legacy gloss. Existing specular maps are not incorrectly treated as metallic maps. Native CommonFilters gains its upstream screen-space light-shaft option in addition to AO, not true volumetric transport. Cg driver support is optional; native fallback stays available. ModernGL shadow uniform binding tolerates compiler elimination of the PCF texel uniform in the volume pass. Installer excludes obsolete Panda Rocket bindings. No third-party assets copied or paid dependencies introduced.
