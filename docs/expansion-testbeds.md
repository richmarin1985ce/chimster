# Expansion-scale native authoring testbeds

Section 3 remains the overriding engineering priority. These original fan expansion projects are downstream integration targets, not claims of playable releases. No retail assets are redistributed.

| Target | Project | Setting |
|---|---|---|
| Fallout New Vegas | Fallout: Route 66 | Existing Flagstaff campaign and surrounding highway region |
| Skyrim | Provisional: Realm of Order | Jyggalag, original realm interpretation; no major Skyrim questline; lore review required |
| Fallout 3 | Fallout: Baltimore (working title) | Baltimore harbor, industrial districts and surrounding neighborhoods |
| Fallout 4 | Fallout: Nautica | Nantucket and maritime locations |
| Classic Oblivion | The Hunting Grounds (working title) | Great Forest werewolf questline leading to an island in Hircine's realm; Remastered compatibility target |
| Morrowind | Coldharbour (working title) | Ruined, distorted reflections of selected Vvardenfell locations; distinct from Project Tamriel |

Target per expansion: approximately 10–15 hours main story and 20–30 hours including optional content, 25–40 authored locations, multiple settlements or hubs, original factions and quests. These are planning targets, not verified equivalence to Dragonborn. Prioritize a small playable vertical slice before expanding content. Each project should exercise native record identity, reference traversal, world/cell hierarchy, dialogue, quests, scripting, NPCs, inventory, localization, assets, conflict handling and save/load validation where supported. TES3 uses its own record identity semantics rather than TES4 FormIDs. Skyrim and FO4 require separate versioned schemas. Retail tests require locally owned game installations; no certification without execution. Separate Skyrim original/SE and FO4 version targets as needed. Additional game families remain outside these six testbeds.

## Oblivion: The Hunting Grounds
Supersedes the cloud realm concept. Original expansion-scale werewolf campaign beginning in Cyrodiil's Great Forest and leading into an island-like region of Hircine's Hunting Grounds. Dawnguard-like supernatural quest structure and Dragonborn-like regional scope; thematic echoes of Bloodmoon, not a sequel or recreation of Solstheim. Include original settlements, wilderness, Ayleid-inspired ruins (Elmazel reference pending clarification), hunters, werewolf factions, transformation mechanics, creature rigs, animation transitions, combat, AI and quest consequences. Classic TES4 baseline; separate Remastered compatibility validation for animation, meshes, scripts and gameplay. No mandatory external script extender unless later explicitly justified. No retail asset redistribution. Section 3 remains overriding engineering priority; expansion is a downstream testbed, not a playable release.
