# Quest Studio and DialogueViews
PR19 passed all seven workflows and merged. New features:
- Native FNV QUST flags (start enabled, repeat topics/stages), delay, global/stage conditions, linked quest script and next quest references. DIAL category and rumor flag. INFO multi-line response numbering, per-line emotion, sound and animation bindings, prompt overrides, next speaker, speech challenge, linked topics and behavior flags.
- Native GECK draft export with embedded source in stage/INFO begin/end result slots. Requires explicit --script-draft when actions are present. No fabricated bytecode. Compile a separate same-name copy in GECK, then use quest-attach-scripts to accept only script collections with identical source, master order, record identities, flags, non-script fields and valid compiled size/reference counts. Never deploy the uncompiled draft. Does not validate opcode semantics or execute the GECK. GECK may change unrelated fields or empty script collections; importer deliberately rejects such donors. Compile individual scripts, not the dangerous Recompile All Scripts operation.
- Creation Kit DialogueViews XML (observed Diagram Version=12) inspection, explicit full FormID mapping, mapped filename, preservation of diagram-internal node IDs, unknown elements/resources and links, and optional node repositioning with link endpoint displacement. Desktop viewer/editor and CLI. Scratch generation of the observed XML subset is now implemented; compact ESL IDs and complete resource templates remain unsupported. Use an existing compatible locally supplied template with matching topology; actual CK load/save verification pending. XML is editor metadata, not the game's runtime dialogue. Native DLBR/DLVW records remain separate work. XML source observed in https://github.com/AndersonPaschoalon/Skyrim-DSilHand/blob/master/Data/DialogueViews/0200AE2C.xml (MIT repo; not copied into project). Regression fixture is original and synthetic. 
- Portable actor/reference/location alias bindings and cinematic scene phase/action timelines; actor overlap, target and time validation. Native Skyrim/FO4 SCEN/QUST alias serialization not yet implemented. New Vegas uses a different native conversation system.
## Commands
    python -m chimster quest-native native.json draft/Quest.esp --script-draft
    python -m chimster quest-attach-scripts draft/Quest.esp compiled/Quest.esp output/Quest.esp
    python -m chimster dialogue-view-inspect Data/DialogueViews/02000800.xml
    python -m chimster dialogue-view-remap Data/DialogueViews/02000800.xml staged/03000800.xml mapping.json --positions positions.json
    python -m chimster quest-scenes scene.json --scene Opening
Mapping JSON maps every view and branch/topic FormID as eight-digit hexadecimal strings, including unchanged IDs. Positions JSON maps diagram node IDs (not FormIDs) to [x,y]. Link geometry is approximated by interpolating endpoint displacement; branch bounds are not auto-resized. No automatic load order guessing. 
References: https://tes5edit.github.io/fopdoc/FalloutNV/Records/QUST.html ; https://tes5edit.github.io/fopdoc/FalloutNV/Records/INFO.html ; https://tes5edit.github.io/fopdoc/FalloutNV/Records/Subrecords/SCHR.html ; https://geckwiki.com/index.php/Recompile_All_Scripts .
