# Calipi

Calipi is an optional, original vector-drawn vernier-caliper parody of 1990s desktop assistants. Enable or disable it with Help > Activate Clippy (Calipi). It starts disabled every launch. Drag the character to reposition; click it (or press Enter/Space when focused) for another scripted tip. Right-click to talk or hide. Speech is via a dismissible text balloon, with animated mouth, eyes and sliding jaw; no audio, AI, telemetry, networking, project writes, or additional dependencies. Tips are local strings keyed to the selected editor tab. When hidden, its scheduled animation and speech callbacks stop. Calipi stays within the editor window and does not interact with project data.

Manual checks: enable/disable repeatedly, drag to all corners, resize, change tabs, dismiss a balloon, right-click hide, close the editor while visible, and confirm editor controls remain usable outside the overlay.
