# Planetary preview

Read-only full-master scan of PNDT (body, radius, gravity, atmosphere, seed, biome links), BIOM (colors, climate and water), STDT and WRLD. Bounded six-face globe, nine local terrain tiles with three LOD tiers, spherical tangent-coordinate sampling, deterministic illustrative relief and explicit physical scale. No claim to reproduce the native Starfield procedural engine. Native SFTR and SFPT arrays can be read on demand as raw bytes, not remapped IDs. Native surface heightfield formats, terrain streaming and weather generation remain open. xEdit and Mutagen disagree on the two PNDT coordinate fields; preserve raw values and expose the convention through the API. Sources: https://github.com/Mutagen-Modding/Mutagen/tree/dev/Mutagen.Bethesda.Starfield/Records and https://github.com/TES5Edit/TES5Edit/blob/dev-4.1.5/Core/wbDefinitionsSF1.pas .
Local landing tiles now have individual instance centers for distance LOD/culling, shared sampled edges and downward skirts to conceal mixed-tier cracks. A user-supplied heightfield can replace illustrative heights: {"version":1,"units":"meters","heights":[[0,100],[200,300]]}. Square 2–513 sample arrays, bilinear sampling, explicit geographic span. This imports provided elevations; it does not decode Starfield terrain assets. Added high-frequency relief for procedural local previews.

Landing streaming uses a moving 3x3 window, a fixed geographic tangent chart, shared overlap mesh identities and a cache of at most 54 tier meshes. Finite imported heightfields stay within their original extent. Surface array summaries retain raw IDs rather than assuming native remapping.

The viewport now recenters the planetary camera after panning, retains preview materials, displays updated geographic coordinates, and exposes native surface-tree summary inspection. Pan-release streaming is enabled for illustrative terrain; imported heightfields remain fixed.

Native CLMT weather/settings references and timing bytes are indexed and exposed through biome climate inspection. Approximate planetary solar lighting uses local latitude and Dawn/Day/Dusk/Night controls, with atmospheric scattering and sun direction updated in both renderers. This is a local solar-time preview, not native weather scheduling or astronomical ephemerides; raw tilt/rotation fields are retained but not assumed to be degrees.

Native Starfield BTDB v5/v6 zero-coordinate terrain subset now reads the height range, LOD4 height/texture arrays and LOD0–3 compressed 128x128 blocks, with bounded decompression and a 16-block cache. Import a local BTD file and select a cell for a terrain preview. Vertical scale is explicit because upstream references note uncertainty about Starfield Z scale; geographic alignment and native texture assignment are not inferred. Format reference: https://github.com/fo76utils/fo76utils/blob/main/src/btdfile.cpp .
