# Native compound collision
Original MIT Python recipe code and separately built GPL Nifly bridge. Experimental static compound NIF output for Fallout 3 and New Vegas. Multiple axis-aligned solid boxes preserve architectural openings rather than covering an entire building with one solid volume. Export uses bhkCollisionObject -> bhkRigidBodyT -> bhkListShape -> bhkConvexTransformShape -> bhkBoxShape. Each child and transform carry its own material ID; the list has an explicit independent material. All 128 documented FO3/FNV IDs are selectable by number or neutral name, including platform/stair variants. The game may use the list material for impact sounds/FX, so distinct child materials are serialized but their runtime effect is not guaranteed.
    python -m chimster building building-output
    python -m chimster modern-nif newvegas building-output/building.obj building.nif /path/to/chimster-nifbridge --scale 10 --compound-collision building-output/collision.json
Choose scale appropriate for the world project, not a universal meter-to-game conversion. Render geometry and collision use the same scale. Recipe example: {"kind":"compound_aabb","list_material":"stone","boxes":[{"id":"floor","min":[0,0,-0.25],"max":[8,6,0],"material":"wood"},{"id":"wall","min":[0,0,0],"max":[0.25,6,3],"material":"stone"}]}.
Limit 256 finite nondegenerate boxes, fixed/static body, root identity, no rotation per box, no dynamic rigid bodies, no convex decomposition, no MOPP/triangle collision. Reopen verifies all child references, shape count, half-extents, transforms and material IDs. The existing seven-game-unit/Havok-unit conversion is inherited from the earlier experimental bridge; independent scale/engine verification is required. Mixed material runtime behavior needs tests of footsteps, sounds, decals and impact effects; if necessary, separate collision nodes or mesh material partitions are future approaches.
References: https://www.niftools.org/nifxml/Fallout3HavokMaterial.html and https://www.niftools.org/nifxml/bhkListShape.html . Skyrim hashes and newer FO4 collision layouts are different; do not reuse the FO3/FNV enum for them.
