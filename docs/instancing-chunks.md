# Instancing and hierarchical scene culling
The OpenGL renderer groups visible instances by selected mesh/LOD and uses per-instance vertex attributes for position, yaw, scale, selection and object ID. Each material/index buffer is drawn once per batch instead of once per object. Picking still identifies individual instances. A cached bounding-volume hierarchy splits instances on the longest axis, with conservative group bounds and exact per-object sphere checks at leaves. Rebuilds when immutable instance tuples or asset identities change. Current meshes are assumed immutable after upload. This is spatial culling, not streamed worldspace paging or a terrain tile engine.
    python -m chimster render-benchmark --count 2500 --frames 5 --backend egl
Compare three modes at identical camera/settings: individual draw + flat culling, instancing + flat culling, instancing + hierarchy. Warmup once per mode; reports median frame milliseconds including framebuffer readback, draw counts, visible/culled objects, LOD and hierarchy tests. CI uses software Mesa llvmpipe. No hardware performance claim. Geometry remains the same across modes. Real GPU, large-world streaming and terrain chunk integration are pending.
