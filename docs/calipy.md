# Calipy

Calipy is an optional, original vector-drawn vernier-caliper parody of 1990s desktop assistants. Enable or disable it with Help > Activate Clippy (Calipy). It starts disabled every launch. Drag the character to reposition; click it (or press Enter/Space when focused) for another scripted tip. Right-click to talk or hide. Speech is via a dismissible text balloon, with animated mouth, eyes and sliding jaw; no audio, AI, telemetry, networking, project writes, or additional dependencies. Tips are local strings keyed to the selected editor tab. When hidden, its scheduled animation and speech callbacks stop. Calipy stays within the editor window and does not interact with project data.

Manual checks: enable/disable repeatedly, drag to all corners, resize, change tabs, dismiss a balloon, right-click hide, close the editor while visible, and confirm editor controls remain usable outside the overlay.

## Ask Calipy
Use the question box or right-click > Ask Calipy to search the bundled wiki. The deterministic language engine matches normalized words, aliases and editor context against headings and article text. Results are presented in original order within the matching section, with Back, Next, Other topic and Wiki controls. The source title and section are shown in every balloon. Unknown questions receive an explicit fallback rather than invented instructions. No neural model, download, project edits or external calls. Help cards remain until dismissed; changing tabs does not interrupt an active guide. Manual UI verification remains necessary.
