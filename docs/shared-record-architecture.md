# Shared record architecture
Classic FNV full-slot identity is (origin plugin, 24-bit local ID), not a load-order integer. Resolve identities before linking or moving fields between master tables. The new graph handles selected exact-length FNV reference fields and rejects opaque payloads during slot changes. It reports missing/deleted targets, wrong types and incoming links; deletion review is conservative rather than a native delete command. No ESL/Starfield assumptions.
Public references: https://tes5edit.github.io/docs/8-managing-mod-files.html ; https://github.com/TES5Edit/fopdoc/blob/master/Fallout3/Records/TES4.md ; https://www.niftools.org/nifxml/index.html . Gamebryo scene-object hierarchy informs separation of identity, payload and linking, not Bethesda plugin binary layouts. No proprietary SDK source used.
