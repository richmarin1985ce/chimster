# Licensing policy

Original Chimster source and documentation are MIT licensed, unless a file explicitly states another license. Contributions must be compatible with the license of their target component.

## Third-party code
- OpenMW/OpenMW-CS: GPLv3. Directly derived components and combined distributions must be distributed under applicable GPL terms, with corresponding source, notices and build instructions. Do not assume the upstream license permits later GPL versions; check individual files.
- JPEXS FFDec: GPL-3.0-or-later application; LGPL library. Verify the version and exact license before redistribution.
- Other tools: verify license at the pinned upstream revision before importing, linking or redistributing. Record SPDX identifier, source URL, revision and copyright notices in a third-party inventory.
- External proprietary editors and game assets are not distributed. Discover user-installed tools and communicate through documented interfaces. Separation is assessed by how components actually interact, not just whether they run as separate processes.
- Generated mods are not automatically MIT licensed; asset and game-specific terms remain applicable.
