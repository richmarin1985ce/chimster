# Asset Forge

The desktop Asset Forge tab combines the existing rock, flora and modular building generators, triangulated OBJ import, shaded CPU preview, material assignments, transformations, vertex-cluster LOD simplification and native export routes.

## Native mesh import (experimental)
Rebuild the optional GPL native helper against the pinned nifly source as described in native/nifbridge/README.md. Use Import NIF, explicitly select the trusted helper, and inspect the preview. The helper's extract-mesh command accepts FO3/FNV, Skyrim LE/SE/VR and FO4/VR file families, restricted to direct root static triangle shapes with identity transforms and UVs. Geometry and UVs, diffuse and normal texture references and the exact supported alpha-test property are carried into the portable mesh; shape IDs are generated. Unknown blocks, skinning, nested/nonidentity shape transforms, unsupported alpha properties and invalid indices are rejected. The original NIF is never modified. Re-export creates a new file and is NOT a lossless native edit: shaders, BGSM/BGEM, collision, custom normals, extra data, names, animations and other native properties are not preserved. Legacy Morrowind/Oblivion native import remains pending.

## Topology
Select vertex, edge or face mode. Click a small preview or enter comma/space-separated zero-based indices. Edges are sorted pairs of shared vertex indices; indices can change after topology edits. Move applies a numeric XYZ displacement to selected vertices or the vertices of selected edges/faces. Split edge divides all incident triangles with midpoint UVs and preserves face winding and material IDs. Delete faces compacts unused vertices, refusing empty meshes; assign faces uses existing material groups. Five-step undo is shared with transforms and LOD operations. Coincident but separate vertices at UV seams remain distinct. Click picking is approximate orthographic screen-space selection, not full depth-buffer picking; large meshes require indexed selection. See advanced editing below; drag gizmos remain pending.

Regression fixtures cover exchange validation, movement, edge splits, deletion, reassignment and undo. Native helper compilation, GUI interaction and retail engine tests remain unverified.

## Advanced editing and projects
Shift-click toggles selections. Right-drag orbits and the mouse wheel zooms. Region extrusion duplicates the selected cap, bridges boundary edges, and preserves material assignments and winding; it rejects nonmanifold/ambiguous selected edges and collapsed side triangles. It does not detect self-intersection or create a bottom cap for an originally open patch. Side UVs inherit cap coordinates and need a separate projection. Weld merges selected vertices to the lowest index only if within tolerance, exact UVs and material memberships agree; duplicate faces are rejected and index-collapsed triangles are removed. Planar UV projection on selected faces duplicates shared boundary vertices to preserve unselected UVs. Numeric UV scale/offset and a bounded wireframe UV preview are provided. Undo/redo holds up to five edits. Save new asset and Open asset use versioned .casset files containing mesh geometry and material references; writes are exclusive, no overwrite, no texture bytes or undo history embedded. Regression fixtures added; execution pending. Full UV unwrapping, texture sampling, transform gizmos, native property preservation and collision authoring remain open.

## Axis gizmos and compound collision
Select vertices, edges or faces, choose move/rotate/scale, and drag a colored axis endpoint. The preview shows the drag guide; geometry commits once on release, with a single undo step. Movement is projected into world units; rotation and scaling are relative to the selection centroid. Rotation uses linear axis drag, not circular rings. This is an orthographic CPU preview, not a full interactive GPU manipulator.
Select geometry and choose Box from selection to add a padded axis-aligned collision proxy. Edit/review boxes opens the complete validated JSON recipe, including individual and list material IDs. Cyan outlines indicate reviewed boxes, orange indicates stale geometry. Geometry/topology changes conservatively mark collision stale; explicit review or replacement is required before compound native export. Undo/redo restores the collision recipe and review state. Schema 2 .casset projects retain collision; schema 1 projects remain readable. Native compound serialization reuses the existing FO3/FNV helper, and is not a native collision editor for other games. AABB recipes do not approximate arbitrary concave geometry automatically. New regression fixtures are included; execution and runtime verification remain pending.
