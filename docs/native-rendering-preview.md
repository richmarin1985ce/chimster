# Native rendering preview

Read-only Fallout: New Vegas adapter for documented LIGH DATA/FMAM, CELL DATA/XCLL/XCLW/XCWT/LTMP/LNAM, LGTM DATA, and WATR FNAM/ANAM/DNAM (or legacy visual DATA). Winning records are resolved by the existing world browser. Color, fog, fade, light radius and water elevation/material settings feed the viewport; the four strongest local lights are bounded to one shadow caster. Negative/off-by-default/initially disabled lights are not previewed. Euler spotlight direction, fog density and water optical response are approximations, not exact game-engine simulation. Only the selected cell's single water surface is represented; per-cell multiple water planes, animated light flicker and other game profiles remain outside this verified format scope. No native writes. Sources: https://tes5edit.github.io/fopdoc/FalloutNV/Records/LIGH.html ; https://tes5edit.github.io/fopdoc/FalloutNV/Records/CELL.html ; https://tes5edit.github.io/fopdoc/FalloutNV/Records/LGTM.html ; https://tes5edit.github.io/fopdoc/FalloutNV/Records/WATR.html .

Fallout 3 uses independently documented matching visual structures, with FNAM rather than FMAM fade and the first byte of PNAM for world inheritance. The Fallout 3 adapter resolves inherited world water and height separately. Other game families remain opaque rather than reusing unverified offsets. See https://tes5edit.github.io/fopdoc/Fallout3/Records/LIGH.html and https://tes5edit.github.io/fopdoc/Fallout3/Records/WRLD.html .
