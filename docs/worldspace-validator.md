# Worldspace Validator
Read-only New Vegas plugin and merged-load-order integrity checks. Supply active plugins in exact order, including all masters:
    python -m chimster world-check Base.esm Patch.esp Merged.esp
Use --strict to return nonzero when warnings are found, as well as errors. Reports include plugin, byte offset, severity, issue code, and details. No plugin is modified.
Checks: group and record sizes, parent group types, owner record preceding child group, duplicate sibling groups, persistent/temporary/visible-distant bucket ownership, conventional top group order (warning), signed exterior block/sub-block Y/X coordinates, interior FormID bucket rules, duplicate FormIDs per plugin, missing/later masters, resolved FormID origin and local ID, effective last-wins duplicate exterior cells and persistent cells, duplicate LAND, orphan world/cell, selected reference bases and landscape texture links, reference position mismatch (warning), malformed landscape subrecords, bounded compressed world records. Relocated CELL/LAND/NAVM overrides are flagged for review. Valid overrides across plugins are not duplicates.
This initial validator is New Vegas-specific; no claim of retail-game verification. It does not compare source and merged plugins for lost records, resolve arbitrary embedded FormIDs, decode navmesh connectivity or check external LOD files. No automatic repair. Canonical ordering rules are distinguished from known structural violations; test on a copied profile.
References: https://tes5edit.github.io/fopdoc/FalloutNV/Groups.html and https://stepmodifications.org/wiki/Guide:Plugins_Files
