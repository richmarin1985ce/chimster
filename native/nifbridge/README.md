# Chimster NIF bridge
Original bridge source: GPL-3.0-only (SPDX in main.cpp), as it links nifly GPLv3. Chimster Python code remains MIT. The native bridge is optional and separately built; do not distribute the linked executable without GPL-compliant corresponding source and notices. Upstream source pinned to https://github.com/ousnius/nifly/tree/47993ec6540a09453f6d53fded6c1eec91dcf3eb ; license text https://www.gnu.org/licenses/gpl-3.0.txt . No upstream source or binary bundled here. Retain upstream dependency notices.
Build: git clone https://github.com/ousnius/nifly ; git -C nifly checkout 47993ec6540a09453f6d53fded6c1eec91dcf3eb ; cmake -S native/nifbridge -B build/nifbridge -DNIFLY_SOURCE=/absolute/path/to/nifly ; cmake --build build/nifbridge --config Release --parallel 2
Supports experimental static mesh serialization for FO3/FNV, Skyrim LE/SE/VR, FO4/VR. Geometry, UV, normals, tangent generation, default shader, diffuse/normal texture slots, optional alpha test. No collision, skin, wind, BGSM material generation, engine LOD tile formats or Starfield .mesh. FO4 defaults may require material adjustment. Round-trip checks are not in-game verification.
